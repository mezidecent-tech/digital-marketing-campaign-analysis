# 📊 Digital Marketing Campaign Analysis

## Project Overview

This project analyses digital marketing campaign performance using Power BI.

The dashboard provides an interactive view of campaign performance across different platforms, campaign types, industries and countries. The project focuses on key marketing performance indicators to help identify trends, compare campaigns and generate actionable business insights.

## 🎯 Project Objectives

The main objectives of this project were to:

* Analyse digital marketing campaign performance
* Compare performance across different platforms
* Evaluate campaign performance by campaign type and industry
* Analyse geographic performance
* Track key marketing KPIs
* Identify patterns and trends in campaign results
* Present marketing insights through an interactive Power BI dashboard

## 🛠️ Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Data Visualisation
* Marketing Analytics

## 📈 Key Performance Indicators

The dashboard analyses the following marketing metrics:

* Impressions
* Clicks
* Click-Through Rate (CTR)
* Cost Per Click (CPC)
* Ad Spend
* Conversions
* Cost Per Acquisition (CPA)
* Revenue
* Return on Ad Spend (ROAS)
* Conversion Rate

## 🔄 Project Workflow

The project followed these main stages:

1. Data collection
2. Data cleaning and preparation
3. Data transformation using Power Query
4. Data modelling
5. Creation of calculated measures using DAX
6. KPI development
7. Data visualisation
8. Dashboard design
9. Analysis and interpretation of results

## 💡 Key Business Questions

The dashboard was designed to answer questions such as:

* Which platforms generate the most clicks and conversions?
* Which campaigns achieve the highest conversion rates?
* How much does it cost to acquire a customer?
* Which campaigns generate the strongest ROAS?
* Which countries demonstrate stronger campaign performance?
* How does campaign performance vary across industries?
* Which campaign types produce stronger results?

## 🔍 Key Insights

The analysis identified patterns in campaign performance across platforms, campaign types, industries and geographic locations.

**Note:** The specific findings should be interpreted from the dashboard data and may depend on the selected filters.
